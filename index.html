Buka Google Spreadsheet ↗

Aplikasi ini membaca data dari Google Sheets. Agar web aplikasi bisa mengirim dan mencatat data serah terima shift serta pasien ke Google Sheets tanpa login Google berulang kali di browser, ikuti 4 langkah cepat berikut (hanya 1 menit sekali saja):

1
Buka Apps Script di Google Sheets:
Buka spreadsheet Anda di browser, klik menu Ekstensi (Extensions) → Apps Script.
2
Salin Kode Backend Script:
Hapus kode default pada editor, lalu salin seluruh kode dari kotak di bawah ini dan tempelkan. Simpan file (Ctrl+S).
3
Terapkan Sebagai Web App:
Klik tombol biru Terapkan (Deploy) di kanan atas → Penerapan baru (New deployment) → Pilih tipe Aplikasi Web (Web app).
Atur: Jalankan sebagai: Saya | Yang memiliki akses: Siapa saja (Anyone).
4
Tempelkan URL Web App & Kirim:
Salin URL yang berakhiran /exec, tempelkan ke kolom input di bawah ini, lalu klik tombol Simpan & Kirim Data Handover.
* Cukup masukkan 1x saja. Setelah disimpan, tombol "Kirim ke Google Sheets" di form dan laporan akan otomatis mengirim data ke spreadsheet tanpa konfigurasi ulang!
